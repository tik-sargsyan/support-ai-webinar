# Automate the Boring Part

A 1-hour intro to automations, AI agents, and the tools behind them (**n8n** + **Claude Code**), made for the Picsart support team.

**▶ Open the deck:** https://tik-sargsyan.github.io/support-ai-webinar/

## What's inside
- Automation vs agent: the one distinction that makes everything click
- **n8n** basics: triggers, steps, and a ticket-triage workflow
- **Claude Code**: the agent loop, tools, MCP, skills, subagents, memory
- Putting it together for support, guardrails, and where to start
